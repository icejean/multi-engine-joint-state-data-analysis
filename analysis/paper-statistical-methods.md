## 一、数据与抽样结构

- **样本**：works_cycles（BIRD AdventureWorks）**126 题**。
- **每档**：每题跑 **3 轮**——同一模型、同一档位、同一题跑 3 次（reasoning 模型即使 temp=0 也非确定，见论文 §7.1④）。
- **数据结构**：`{ 题ID: [第1轮对/错, 第2轮, 第3轮] }`，共 126 个三元组。
- **关键事实**：同一题的 3 轮**高度相关**（同题、同模型、难度固定），**不是 3 个独立样本**。这一条决定了 §三 里 bootstrap 的抽样单位必须是「题」而不是「作答」。

## 二、口径定义（指标字典）

| 指标 | 别名 | 定义 | 角色 |
|---|---|---|---|
| **平均（三轮）** | pass@1 | 三轮里答对的作答数 ÷ (3×126)，即 378 次作答的答对比例 | 能力口径（点估计） |
| **三轮全对** | pass^3 | 三轮全对的题数 ÷ 126 | 可靠性下界（用户实际只跑一次） |
| **并集** | ≥1 对 | 三轮里至少一次对的题数 ÷ 126 | 能力上界（给三次机会） |
| pass@2 | ≥2 对 | 三轮里至少两次对的题数 ÷ 126 | 中间档 |
| pass@k | ≥k 对 | 三轮里至少 k 次对的题数 ÷ 126 | 采样曲线 |
| 三轮极差 | — | 三轮各准确率的最大值 − 最小值 | **误导指标，论文不用**（见 §五） |
| **漂移题占比** | drift-question ratio | 三轮里 1~2 次对的题数 ÷ 126 = 并集 − 三轮全对 | 衡量「漂移题」多少 |
| **轮间漂移率** | 翻转率 flip rate | Σ(相邻两轮「对→错/错→对」翻转次数) ÷ (126 × 2) | 相邻轮答案翻转的概率 |

> 三者关系（不重复）：**并集 = 三轮全对 + 漂移题占比**；「平均」数值上介于二者之间。
> 论文 §4.2 的「平均 / 三轮全对 / 并集」三个列，就是上表前三行。

## 三、bootstrap 95% 置信区间（核心）

### 算法（对应 `bootstrap_ci()`）

1. **抽样单位 = 题**（不是 378 次作答）。每次抽「一整道题」，连同它的三轮结果一起抽。
2. **有放回抽 126 题**：`rng.randrange(126)` 均匀抽取、允许重复，拼成一个「新题集」。
3. 在新题集上重算指标：
   - 平均 = Σ(新题集所有答对) ÷ (3 × 126)
   - 三轮全对 = (新题集里三轮全对的题数) ÷ 126
4. **重复 `n_boot = 10000` 次**，得到 10000 个 bootstrap 值。
5. 排序后取 **第 2.5% 与第 97.5% 分位**（`vals[250]`、`vals[9750]`）= 95% CI。

### 三个设计选择及理由

| 选择 | 理由 |
|---|---|
| **题级重采样**（非作答级） | 同题三轮相关；按 378 次作答独立抽会**低估不确定性、区间偏窄** |
| **百分位法**（非 BCa / 正态近似） | 简单、标准；对 n=126 的比例指标足够；不依赖正态假设 |
| **`seed=42` + 10000 次** | 固定种子可复现；**实测换 seed 结果不变**（见 §六 Q6） |

### 只对哪些指标配 CI

CI 只对 **平均** 和 **三轮全对** 两个**估计量**计算；**并集不配 CI**——它是「三轮至少一次对」的**确定性计数**，不是抽样估计量（论文 §4.2 表 1 下的注即此意）。

## 四、McNemar 配对检验

### 计算原理（从零讲清）

**它解决什么**：同一批 126 题被两种方法（M+S 与 single-shot）各测一次，每题为对/错——这是**配对数据**，不是两组独立样本。

**2×2 表**：按「两种方法各自对错」把 126 题分四格：

| | B 对 | B 错 |
|---|---|---|
| **A 对** | a（都答对） | **b（A 对 B 错）** |
| **A 错** | **c（A 错 B 对）** | d（都答错） |

**核心思想——只看 b、c**：一致对 a、d 由**题目难度**决定（简单题都答对、难题都答错），不反映方法优劣；真正的方法差异只在**不一致对** b、c 里——b 大 = A 赢，近似 50/50 = 半斤八两。所以 McNemar **丢弃 a、d，只在 b+c 道不一致题上检验**。

**零假设 H0**：两方法正确率相同 ⇒ 每道不一致题偏向谁纯属抛硬币 ⇒ `b ~ Binomial(b+c, 0.5)`。观察到的 b 离中间值越远越该拒绝 H0。

**手算两例（论文真实数字）**：

- M+S vs S1（并集口径）：`b=7, c=0` ⇒ `p = 2 × C(7,0)/2^7 = 2/128 = 0.0156`——7 道不一致题 M+S 全赢，抛 7 次硬币全朝一边的概率 1/128，双侧 1/64 < 0.05 → 显著。
- M+S vs M1（并集口径）：`b=1, c=3` ⇒ `p = 2 × (C(4,0)+C(4,1))/2^4 = 2×5/16 = 0.625`——4 道不一致题 M+S 输 3 赢 1 → 不显著（即「M+S 与纯 M 打平」）。

**为什么这里不能用卡方独立性 / t 检验**：

| 检验 | 数据 | 用什么 | 结论 |
|---|---|---|---|
| 卡方独立性 | 两组**独立**样本 | 全部 a,b,c,d | 两变量是否相关 |
| t 检验 | **连续**数值 | 均值+方差 | 均值是否不同 |
| McNemar | **配对**二元结果 | 只 b,c | 两方法错误率是否相同 |

若拿卡方独立性把 126×2 当两组独立样本、把一致对也当「证据」，等于把**题目难度驱动的数据**当成方法差异，虚增样本量、给出过于自信的 p 值。McNemar 丢弃一致对，只留方法差异信号，才是对的。

**为什么精确二项、不用卡方近似**：卡方近似在 `b+c` 大时才准；论文里不一致对常很小（如 b+c=7），卡方近似失真。精确二项任何 b+c 都精确。卡方近似形式（备查）：`χ² = (b−c)²/(b+c)`（df=1），连续校正版 `(|b−c|−1)²/(b+c)`。

### 配对口径（每题一个二元结果）

McNemar 需要「每题一个二元结果」，用两种口径：

- **并集口径**：该题三轮**至少一次对** = 1（否则 0）
- **全对口径**：该题三轮**全对** = 1（否则 0）

> 注意：McNemar **不直接对「平均」检验**（平均是每题 0/1/2/3 的多值），只用上述两个二元口径。

### 精确二项公式（不依赖 scipy）

设 `b` = 「A 对 B 错」的题数、`c` = 「A 错 B 对」的题数（不一致对），`n = b + c`。零假设下不一致对 50/50 分裂，即 `b ~ Bin(n, 0.5)`，双尾 p 值：

```
p = 2 × Σ_{k=0}^{min(b,c)} C(n,k) / 2^n
```

用**精确二项**而非卡方近似，因为 `b + c` 可能很小（见 §六 Q4）。

### 结果（M+S M0 vs 各对照，works_cycles）

| 对照 | 并集口径 (b, c, p) | 全对口径 (b, c, p) |
|---|---|---|
| vs S1（single-shot 字典） | b=7, c=0, **p=0.0156** | b=14, c=7, p=0.1892 |
| vs S2（single-shot 满配） | b=8, c=2, p=0.1094 | b=16, c=3, **p=0.0044** |
| vs M0（纯探索 裸） | b=3, c=2, p=1.0000 | b=14, c=10, p=0.5413 |
| vs M1（纯探索 字典） | b=1, c=3, **p=0.6250** | b=8, c=5, p=0.5811 |
| vs M2（纯探索 满配） | b=1, c=3, **p=0.6250** | b=11, c=7, p=0.4807 |

论文三条核心结论对应的检验：

1. **M+S ≈ 纯 M（无显著差）**：p=0.625（并集口径，vs M1/M2）。
2. **M+S 显著优于 single-shot（能力）**：并集口径 vs S1，b=7 c=0，**p=0.0156**。
3. **M+S 显著优于 single-shot（可靠性）**：全对口径 vs S2，b=16 c=3，**p=0.0044**。

### 延伸到 B1（financial / formula_1，同库 single-shot 基线）

同一套配对 McNemar（脚本 `scripts/analyze_b1_singleshot.py`），核心：能力口径（并集）下 M+S 几乎**不丢** single-shot 能对的题（c≤1）、只**净增**（b=16~43），p<0.0001。明细见 `p2-statistical-results.md` §B1。

## 五、设计理由速查

| 决策 | 为什么 |
|---|---|
| bootstrap 抽样单位 = **题** | 同题三轮相关；按作答抽会低估不确定性 |
| bootstrap 用**百分位** | 简单标准；尊重题级结构；不依赖正态 |
| CI 只给**平均 / 三轮全对** | 并集是确定性计数，非估计量 |
| McNemar 用**精确二项** | b+c 可能小，卡方近似在小样本不准 |
| **不用「三轮极差」** | 三轮极差是噪声主导，可因漂移题轮级互相抵消而巧合变小（M2 0.8pp < M+S 1.6pp）；真正的方差看**漂移题占比** |
| 点估计**必配 CI** | 126 题下 CI 宽约 8pp，裸写单点数字会夸大精度 |

## 六、常见问答（FAQ）

**Q1：为什么 CI 只给「平均」和「三轮全对」，不给「并集」？**
A：并集是「三轮至少一次对」的确定性计数，不涉及「换一批题会怎样波动」，不是抽样估计量，故不配区间。平均 / 三轮全对是估计量，需配 CI 表达不确定度。

**Q2：为什么重采样单位是「题」而不是 378 次「作答」？**
A：同一题的三轮高度相关（同题、同模型、难度固定）。若按 378 次作答独立重采样，等于把相关的当独立，区间会**偏窄**、低估不确定性。126 题才是有效样本量。

**Q3：为什么用 bootstrap 百分位，而不是正态近似或 Clopper-Pearson 精确二项？**
A：① bootstrap 能按「题」重采样，正确处理三轮相关；Clopper-Pearson 只适用于独立 Bernoulli（对「三轮全对」勉强可用、对「平均」不适用），无法统一两种口径。② 正态近似对 66%–95% 的比例虽接近，但 bootstrap 不依赖正态假设。③ 实测两者差异 <0.5pp，结论不受影响。

**Q4：为什么 McNemar 用精确二项，不用卡方近似？**
A：McNemar 只依赖不一致对 (b, c)，而 b+c 可能很小（如 M+S vs S1 并集口径 b+c=7）。卡方近似在小样本不准；精确二项检验任何样本量都有效。脚本纯 Python 实现（`math.comb`），无 scipy 依赖。

**Q5：126 题这么小、CI 宽 8pp，结论还可靠吗？**
A：① CI 宽是样本量的诚实反映，论文明确「点估计必须配 CI」。② 显著性不靠 CI 宽度、而靠配对 McNemar——配对设计大幅降方差，即使不一致对少（b=7, c=0）也给出 p=0.0156。③ 每条核心结论都配了精确 p 值，不裸写点估计。

**Q6：10000 次重采样够吗？seed=42 是否人为选定、会不会影响结果？**
A：10000 次对百分位 CI 已充分稳定（标准做法）。seed=42 仅为可复现；**实测 6 个不同 seed（0/1/7/42/123/2024）下，M+S M0 的 CI 完全一致（平均 86.8–95.2%、三轮全对 79.4–91.3%）**——bootstrap 分布已收敛，seed 不影响任何结论。

**Q7：「三轮全对」是不是过严、甚至三轮其实是同一个模型（伪独立）？**
A：三轮全对是「可靠性下界」——真实场景用户只跑一次，三轮全对才是「用户这次就能拿到正确结果」的下界估计。三轮不是独立采样（这正是 bootstrap 按题抽的原因），但作为稳定性指标有意义：它衡量「这题换 3 次采样能不能稳」。

**Q8：论文写「准确率打平 91.3% vs 91.0%（p=0.625）」，这个 p 对应哪个口径？**
A：91.3% / 91.0% 是**平均**点估计；p=0.625 是**配对 McNemar（并集口径，M+S vs M1/M2，b=1 c=3）**。McNemar 需每题二元结果，故用「并集 / 全对」两种口径、不直接对「平均」检验。两种口径下 p 都 >0.5（并集 0.625、全对 0.581/0.481），结论一致：无显著差。
